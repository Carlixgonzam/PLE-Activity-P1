What Rascal is doing

This page has no game logic. Every key you press, and every tick of the clock, sends a request to a Rascal program that is actually running on this computer. Rascal decides where the snake goes, whether it hit a wall or itself, and when to place new food. This page only draws whatever Rascal sends back.

browser --request--> bridge.py --request--> Rascal browser <--state----- bridge.py <--state----- Rascal

bridge.py only relays messages, it never decides anything about the game itself.
